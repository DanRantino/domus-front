# Domus Web

Frontend da Domus: React + Vite + TypeScript, React Router, Redux Toolkit / RTK Query, MUI, React Hook Form, i18n, Zod, Vitest e Storybook.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abra `http://localhost:5173` (ou `https://web.domus.dev`).

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm test
npm run storybook
```
